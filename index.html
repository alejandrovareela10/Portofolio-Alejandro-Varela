PROYECTO 01 · REDES

CoreNova — Diseño de una red empresarial

Diseño y simulación de la infraestructura de red de una empresa tecnológica ficticia con más de 120 empleados distribuidos en distintos departamentos. La topología se realizó en Cisco Packet Tracer con un switch multicapa como núcleo y switches de acceso para conectar los equipos finales.

Cisco Packet TracerVLANInter-VLAN routingDHCPTrunksTelefonía IP

Topología general de CoreNova: red segmentada por departamentos, conectada mediante una infraestructura centralizada.

Objetivos del proyecto

  • Diseñar y simular una red empresarial organizada por departamentos.
  • Separar el tráfico mediante VLAN independientes para Dirección (10), Recursos Humanos (20), Administración y Finanzas (30), Marketing (40), Ventas (50), Logística (60), Informática (70), Soporte (80), voz IP (90) y servidores (100).
  • Permitir la comunicación entre VLAN mediante un switch multicapa Cisco 3560.
  • Automatizar la asignación de direcciones IP con DHCP y configurar una VLAN dedicada a telefonía IP.

Configuración y tecnologías

  • Switch core de capa 3 y switches de acceso Cisco 2960.
  • SVI y comando ip routing para el enrutamiento entre VLAN.
  • Puertos de acceso asignados a las VLAN de departamento y enlaces trunk para transportar varias VLAN entre switches.
  • Router Cisco 2811 con pools DHCP independientes para las distintas redes.
  • VLAN 90 para voz IP con teléfonos Cisco 7960; VLAN 70 destinada a Informática y administración de la infraestructura.

Qué aprendí

El proyecto me permitió practicar la segmentación de redes, la configuración de switches, el routing inter-VLAN, DHCP, los enlaces trunk y la organización de una infraestructura de red empresarial.

PROYECTO 02 · LENGUAJES DE MARCAS

AeroMundo — Web informativa sobre aviación

Desarrollo de una página web informativa dedicada a los tipos de aeronaves y al mundo de la aviación. La página principal presenta el sitio y permite navegar a distintas secciones sobre aviones comerciales, privados, de carga y militares, además de contenidos sobre motores, historia, galería y contacto.

HTML5CSSEstructura multipáginaNavegación

Estructura de HTML

El documento principal utiliza elementos HTML para separar las partes de la web:

  • <header>: contiene el logotipo, el título AeroMundo y el menú de navegación.
  • <nav> y listas <ul>/<li>: organizan los enlaces, incluidos los submenús de tipos de aeronaves.
  • <main>: agrupa el contenido principal y una tarjeta de bienvenida.
  • <div class="slider">: organiza una serie de imágenes y títulos de categorías de aviones.
  • <footer>: muestra el pie de página con el nombre y el año.

Organización del CSS

La página enlaza hojas de estilo externas para mantener separados el contenido y la presentación: css/styles.css para estilos generales y css/index.css para los estilos específicos de la página de inicio. Las clases del HTML permiten aplicar estilos a elementos como el logotipo, el menú, el slider, las tarjetas y el aviso de cookies.

Interactividad y navegación

El menú enlaza con páginas HTML independientes para cada tema. El código también incluye un aviso de cookies con un botón que llama a aceptarCookies(), cuya función está referenciada desde paginas/cookies.js. El funcionamiento exacto depende del contenido de ese archivo JavaScript.

Qué demuestra este proyecto

Práctica de estructuración semántica de una página, creación de navegación con enlaces internos, uso de hojas de estilo externas y organización de un sitio con varias secciones y recursos gráficos.
